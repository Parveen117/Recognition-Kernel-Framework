# SC-03 — Distributional Seam-Curvature Theorem

## 1. Regular seam

Let \(U\) be a smooth manifold chart and let

\[
\Sigma=\{\rho=0\}
\]

be a regular hypersurface, so

\[
d\rho\neq0
\quad\text{on }\Sigma.
\]

Write

\[
U_-=\{\rho<0\},
\qquad
U_+=\{\rho>0\}.
\]

Let \(\alpha_-\) and \(\alpha_+\) be \(C^1\) 1-forms extending continuously to
their respective sides of \(\Sigma\).

## 2. Piecewise process form

With \(H\) the Heaviside distribution, define

\[
\alpha
=
\alpha_-+H(\rho)(\alpha_+-\alpha_-).
\]

This is a piecewise-smooth process form.

## Theorem 2.1 — Seam-jump curvature formula

In the sense of distributional differential forms/currents,

\[
\boxed{
d\alpha
=
d\alpha_-
+
H(\rho)\bigl(d\alpha_+-d\alpha_-\bigr)
+
\delta(\rho)\,d\rho\wedge(\alpha_+-\alpha_-).
}
\]

Equivalently,

\[
d\alpha
=
(1-H(\rho))d\alpha_-
+
H(\rho)d\alpha_+
+
\Omega_\Sigma,
\]

where

\[
\boxed{
\Omega_\Sigma
=
\delta(\rho)\,d\rho\wedge(\alpha_+-\alpha_-)
}
\]

is the seam-supported singular curvature current.

### Proof

Use the distributional Leibniz rule:

\[
d\alpha
=
d\alpha_-+
dH(\rho)\wedge(\alpha_+-\alpha_-)
+
H(\rho)d(\alpha_+-\alpha_-).
\]

The chain rule for the Heaviside distribution gives

\[
dH(\rho)=\delta(\rho)d\rho.
\]

Substitution yields the formula. ∎

## 3. Seam residue

Let \(i:\Sigma\hookrightarrow U\) be inclusion. Define the tangential jump
residue

\[
\boxed{
R_\Sigma
=
i^*(\alpha_+-\alpha_-).
}
\]

Only this tangential jump contributes to \(\Omega_\Sigma\). A jump purely in the
normal \(d\rho\) component wedges to zero with \(d\rho\).

## Theorem 3.1 — Positive defining-function invariance

If

\[
\widetilde\rho=f\rho
\]

with \(f>0\) smooth near \(\Sigma\), then

\[
\boxed{
\delta(\widetilde\rho)d\widetilde\rho
=
\delta(\rho)d\rho
}
\]

as cooriented currents. Hence the seam-curvature current does not depend on the
positive rescaling used to define the same cooriented hypersurface.

### Proof

On the support of \(\delta(\rho)\), terms proportional to \(\rho\,df\) vanish,
while \(\delta(f\rho)f=\delta(\rho)\) for \(f>0\). ∎

```text
+

```

The singular term is generated by non-smooth gluing, not by a smooth coordinate
flip.
