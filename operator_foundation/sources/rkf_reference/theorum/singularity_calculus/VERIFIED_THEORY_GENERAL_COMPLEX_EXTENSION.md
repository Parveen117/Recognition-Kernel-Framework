\[
\boxed{

=
\sum_{r=0}^{|I|-1}
(-1)^r\Delta_{i_r}c_{I\setminus\{i_r\}}.

\[
\boxed{D_\Delta^2=0.}

## 2. Total stratified differential

Let each codimension stratum carry a differential graded coefficient module
\(B_I^p\), with stratumwise differential \(d\), and let the jump maps preserve

\[
d^2=0,
\qquad
D_\Delta^2=0,
\qquad
dD_\Delta=D_\Delta d.

\[
\boxed{
\mathbb D=d+(-1)^pD_\Delta.

\[
\boxed{\mathbb D^2=0.}
\]

normal-crossing compatibility into one total complex.

## 3. Realizability obstruction

If independently declared codimension-\((k+1)\) data \(c\) are claimed to arise
from lower data \(b\), then

\[
c=D_\Delta b
\]

requires

\[
\boxed{D_\Delta c=0.}
\]

Hence

\[
\boxed{
D_\Delta c\neq0
\Rightarrow
\text{definite incompatibility with every lower-stratum realization}.
}
\]

If \(D_\Delta c=0\), that is only the local compatibility gate. Exactness is
governed by

\[
\boxed{
H^k_\Delta=\ker D_\Delta/\operatorname{im}D_\Delta.

The total complex has the analogous cohomology

\[
H^r_{\mathbb D}=\ker\mathbb D/\operatorname{im}\mathbb D,

so \(\mathbb D\)-closure is likewise necessary but not automatically sufficient
for global reconstruction.

- nontransverse singular-stratum calculus;
- infinite seam-family convergence;
- acyclicity of the jump or total complex;
- global potential reconstruction from closed data;
- automatic winding transitions;
