# Native foundation order and correction boundary

Author: Monty Dabas. Reconciled development edition, 26 September 2026.
Classification: source/dependency protocol, with the mathematical continuation in NATIVE_LAURENT_JET_REPAIR.md.

## The source order is binding

The recovered MP native-operator ledger uses

    typed cut/refinement -> signed cut scalar -> oriented quarter turn
    -> native cut-complex field -> residue-bearing path composition
    -> declared completion -> native pairing/action where derived
    -> a coordinate or physical representation only under its own theorem.

NR7/NR8 distinguish the exact cut-rational field from its completion and later complex coordinate chart. NR1 separates source and target identities. NR10 defines an aperture by p^2=p=p^dagger and retains the entire admitted residue fibre. The current continuation consumes these objects rather than replacing them with a primitive ordinary Hilbert space.

RH F06 explicitly derives bounded adjointable maps from a previously established positive native pairing. Its ordinary Hilbert chart occurs in a later conditional section. F07/F08 are subsequent representation and compactness developments, not evidence that an ordinary Hilbert space was an original axiom. Native boundedness and pairing are useful derived tools and must not be deleted because a coordinate analogue is familiar.

## Four distinct roles

1. **Native algebra:** typed paths, local units, cut scalars, dagger, exact products, formal continuation and algebraic quotients.
2. **Native completion/derived pairing:** the specific gauge, Cauchy object and pairing established in the source. Its hypothesis list travels with it.
3. **Representation-specific theorem:** a proved chart may transport the native object into an ordinary operator representation. An explicitly imported self-adjoint/strong-resolvent theorem belongs here, not in the primitive layer.
4. **Physical adapter:** source selection, detector, metric scale, physical time and empirical prediction. These are not inferred from algebraic notation.

The dependency gate is target-specific. It is not a search-and-delete rule for the word 'Hilbert'. It checks the declared dependency graph and rejects a primitive-Hilbert, representation-shadow, external analytic-import or physical-adapter ancestor of the new algebraic jet result. It does not prove that a source author has stated every hidden assumption.

## Correction must use the source's own predicate

For a native aperture p, idempotence is already required. Therefore the formal calculation

    A(t)=t^2 p,
    A(t)^-1=t^-2 p,
    [t^-1](A^-1 A')=2p,
    (2p)^2-2p=2p != 0

uses native multiplication and characteristic-zero cut scalars only. No ordinary inner product, orthogonality, norm, real spacetime, contour or physical clock is introduced. The inverse is in the unital corner with identity p.

The valid logarithmic-residue identity is retained. The invalid universal identification of that residue as a projector is not retained. The replacement is a formal jet-memory module derived from the same pencil. This is a scoped correction to Section 11 of one pinned manuscript, not rejection of the native framework or of its other spectral reconstruction results.

## New hypotheses, made explicit

The new jet construction declares a central formal continuation symbol t and, for its finite length theorem, a finite free cut module and a polynomial or formal power-series pencil with nonzero determinant. These hypotheses are not presented as being uniquely selected by nature. Formal coefficient identities require no analytic contour and no convergence. An analytic interpretation would need a later admissible chart/convergence contract.

The module quotient is not claimed to be a two-sided ideal quotient of the entire native path algebra. Its basis is a computational choice; its dimension and continuation action up to isomorphism are the invariant outputs. A positive native pairing on that quotient, if needed later, is an additional construction, not silently inherited.
