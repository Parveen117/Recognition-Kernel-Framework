## 2. Why the named Morphic manuscripts were easy to miss

The collected-volume assembler recursively discovers Markdown under `RKF/theorum`, but then restricts its main theorem list to files directly in that directory. Its explicit RKF LaTeX inclusion is the completed-Weil endpoint paper. It does not recursively include `theorum/morphic_algebra/main.tex` or `theorum/morphic_geometry/main.tex`.

The inspected book manifest records the older theorem ladder through T48, followed by its other selected source families. A book containing many operator chapters is therefore not evidence that it contains every later Morphic or Pāṇinian manuscript. No build, branch merge or index can silently upgrade the historical manifest into a complete current source census.

The complete **named manuscripts examined here** were fetched from the corrected RKF commit `927cdb6ca98221c0b4285da953a2c8b689fb202c`:

This is a location distinction, not an assertion that no deleted historical or unreviewed file elsewhere ever carried the same title. Selected source sections, rather than every line of both manuscripts, were read in this pass.
