# Theorum

This folder collects the certified RH-framework theorem packets transferred out of `Parveen117/MP` so the Recognition Kernel Framework repository has one clean, readable theorem surface.

The spelling `theorum` is intentional because this folder follows the working-language request. The files below are theorem capsules, not raw manuscript drafts and not executable proof-lab modules.

1. `01_positive_eta_path_independence.md`  
   Fixed five-label UGD/amplitude-lift path equality for every positive eta.

2. `02_seam_integer_single_sector_reduction.md`  
   Reduction of the completed-Weil sign decision to one rank-at-most-five seam integer, with the even sector represented upstream but not an independent terminal gate after the source-sign/favorable-even reduction.

3. `03_m3_positive_accepted_block.md`  
   Certified exact positivity of the target-local reduced anti-seam scalar `M3`, and the resulting positive odd accepted block.

4. `04_zero_cut_t03_endpoint_completion.md`  
   Zero-cut T03 endpoint completion: invariant source-Gram identity, projection-defect positivity and endpoint Schur closure.

5. `05_transfer_boundary_and_next_gate.md`  
   What was transferred, what remains open, and how to continue without reopening already certified results.

6. `provenance.json`  
   Machine-readable pointer list back to the MP pull requests and theorem claims.

## Non-promotion discipline

The transferred capsules preserve the claim boundaries from the MP journey. In particular:

```text
positive-eta path equality              CLOSED on fixed five-label carrier
M3 target-local positivity              CLOSED
seam-integer / five-matrix reduction    CLOSED as reduction
zero-cut T03 endpoint theorem           TRANSFERRED AS CERTIFIED SOURCE RESULT
raw proof-lab code execution            NOT MOVED HERE
new manuscript editing                  NOT PERFORMED HERE
```

Where an MP theorem states a classical explicit-formula or Weil-criterion membrane, this folder records that membrane as a cited/imported terminal interface rather than pretending it was rederived from scratch. Tiny mercy: the folder is clean enough that future-us will not need excavation equipment and a headlamp.
