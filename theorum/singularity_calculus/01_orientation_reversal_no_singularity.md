# SC-01 — Smooth Orientation Reversal Does Not Create a Singularity

## 1. Source claim under audit

The source draft proposed that the coordinate swap

\[
F(T,V)=(V,T)
\]

has a vanishing Jacobian determinant at a distinguished center and that this rank
drop creates the singularity.

That claim is false for the stated map.

## 2. Exact Jacobian

The derivative is constant:

\[
DF
=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix},
\]

hence

\[
\boxed{\det DF=-1.}
\]

Therefore \(F\) is a smooth global diffeomorphism and is orientation reversing,
not rank deficient.

## Theorem 2.1 — Orientation-reversal no-singularity theorem

Let \(F:M\to N\) be a \(C^1\) diffeomorphism and let \(\alpha\) be a \(C^1\)
differential form on \(N\). Then

\[
\boxed{
d(F^*\alpha)=F^*(d\alpha).
}
\]

Consequently a smooth orientation-reversing diffeomorphism with
\(\det DF<0\) but \(\det DF\neq0\) does not, by itself, create a singular
measure term in the curvature.

### Proof

Naturality of the exterior derivative gives

\[
d\circ F^*=F^*\circ d.
\]

Because \(F\) is smooth and invertible, the pullback of a smooth form is smooth.
No delta-supported or other singular current is created. Orientation reversal
changes the sign of oriented integrals where appropriate; it does not create a
rank defect. ∎

## Corollary 2.2 — What can create a genuine seam singularity

A singularity requires additional structure, for example:

- a non-smooth gluing law across a hypersurface;
- a genuinely rank-deficient map;
- collapse/quotient of the carrier;
- a zero or gap-closing event in a phase/topological carrier;
- a distributional source or jump condition.

The coordinate swap \(F(T,V)=(V,T)\) is none of these.

## Recognition interpretation

This theorem prevents a useful category mistake:

```text
orientation reversal != Recognition seam.
```

A Recognition seam must be generated by an actual loss/gluing/obstruction datum,
not by a smooth relabeling with negative determinant.
