## Fail-closed rule

A later domain adapter may consume the topological sector-change theorem only
after declaring:

1. the phase/nonvanishing carrier;
2. the admissible homotopy class;
3. the seam condition where that carrier fails;
4. whether the target depends on lifted branch memory;
5. the connection/curvature object, if curvature is invoked;
6. the representation/gap assumptions used for any spectral-flow statement.

Without those declarations, an observed phase spike or curvature threshold is
not automatically a certified topological transition.
