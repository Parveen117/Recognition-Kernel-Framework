## 0. The domain in the text's own words

> 4.1.76 *taddhitāḥ* ; 4.1.82 *samarthānāṁ prathamād vā* ; 4.1.83 *prāg dīvyato 'ṇ* ; 4.1.1 *ṅyāpprātipadikāt* ; 1.2.46 *kṛttaddhitasamāsāś ca*

A taddhita is an affix of the adhikāra 4.1.76 (to 5.4.160), added to a
prātipadika (4.1.1) in a stated sense (4.1.92 ff.); it is added to the
**first** of the *samartha* words of the vigraha (4.1.82: *prathamāt* — the
word named first in the sense-sūtra, *tasya* in *tasyāpatyam*), and it is
**optional** (4.1.82 *vā*, an adhikāra across the section: the vigraha
*upagor apatyam* remains a licensed sentence beside *aupagavaḥ*). The
default affix is aṇ (4.1.83, up to 4.4.2 *dīvyati*), then ṭhak (4.4.1
*prāg vahateṣ ṭhak*), then cha (5.1.1 *prāk krītāc chaḥ*), then ṭhañ
(5.1.18 *prāg vateṣ ṭhañ*): the section is organised as **four default
affixes with their exceptions**.

## 1. Definitions

**D1 (the taddhita record).** `t = (π, α, σ, g)` — base prātipadika π
(with its last sound, its first vowel, its gender and its gaṇa
memberships as inputs), affix teaching form α with its markers read by
theorum/82, sense σ chosen from the sense heads of D2, and the resulting
prātipadika (1.2.46) with category by D5. The *samartha* condition
(2.1.1 *samarthaḥ padavidhiḥ*) guards the input exactly as in theorum/118
D2: *upagoḥ* must depend on *apatyam* in the vigraha.

**D3 (the modal law).** 4.1.82 *vā* makes every taddhita formation of the
section optional beside its vigraha; local *nityam* (5.1.64 *chedādibhyo
nityam*, 5.2.118 *… ṭhañ nityam*) withdraws the option; local *vibhāṣā* /
*anyatarasyām* (5.1.4, 5.1.122 *imanij vā*, 5.2.96, 5.2.136, 5.3.64,
5.3.68, 5.3.93) opens an option **between affixes**; *bahulam* (5.2.122)
is declared. The output is a set: {aupagavaḥ, upagor apatyam};
{prathimā, pṛthutvam, pṛthutā}; {śreṣṭhaḥ, praśasyatamaḥ}? — no: 5.3.60
*praśasyasya śraḥ* is a substitution, not an option (śreṣṭha only, with
jya by 5.3.61 *jya ca* giving jyeṣṭha as a second substitute).

extends it to qualifiers. Lup is the one deletion whose *yuktavat* law

case for retained history (§6).

## 2. Lemmas

**L1 (the default affix is a function of position).** The four adhikāras
4.1.83 aṇ · 4.4.1 ṭhak · 5.1.1 cha · 5.1.18 ṭhañ partition 4.1.83 –
5.1.63 by the sense-sūtra's position; every affix-sūtra inside names its
exception. Hence `AFFIX(σ, π) = exception(σ, π) if listed else default(σ)`
— a total function up to gaṇa inputs. ∎

**L2 (the vṛddha saṁjñā decides aṇ vs cha in śeṣa).** 1.1.73 *vṛddhir
yasyācām ādis tad vṛddham* (with 1.1.74 *tyadādīni ca*, 1.1.75 *eṅ prācāṁ
deśe*): a base whose first vowel is a vṛddhi vowel (ā, ai, au) is
*vṛddha*; in the śeṣa sense 4.2.114 *vṛddhāc chaḥ* puts cha after it,
otherwise 4.2.92's aṇ. So *śālā* (first vowel ā) → śālīyaḥ, but *grāma* →
grāmyaḥ? — no: grāma takes ya by 4.2.94 *grāmād yakhañau* (an exception
clause); the plain contrast is *śālīyaḥ* (cha) vs *vānaspatyaḥ*? — a
clean pinned pair is left to the certificate (§8); the lemma is the rule,
not the pair. ∎

**L3 (the first-vowel vṛddhi is one event with a position guard).**
7.2.117 acts on the first vowel; 7.3.3 relocates it when that vowel is
followed by a pada-final y / v (the aic goes before them: vi-ākaraṇa →
vai-y-ākaraṇa); 7.3.1 – 7.3.2 and 7.3.4 – 7.3.9 are lexical exceptions.
This is the same VRDDHI event as in theorum/103 with the 7.3.3 branch
added. ∎

**L4 (comparison is ṭi-lopa + substitution + the affix).** iṣṭhan /
īyasun need 6.4.155 (ṭi dropped) on every base, then one of 6.4.156 –
6.4.161 on the listed bases, then iṣṭha / īyas; tarap / tamap need nothing
(5.3.55 – 57 allow them on any base, including after tiṅ by 5.3.56). So
*paṭutara* and *paṭīyas* coexist for one base by 5.3.57 / 58 (set-valued
output). ∎

**L5 (the bhāva affixes partition by the base class).** tva / tal
everywhere (5.1.119); imanic *vā* on the pṛthvādi list (5.1.122) — so the
set {prathimā, pṛthutvam, pṛthutā}; ṣyañ *ca* on varṇa / dṛḍhādi (5.1.123)
and on guṇavacana / brāhmaṇādi also in karman (5.1.124). ∎

**L6 (lup retains the deleted affix's agreement).** By 1.2.51 the
gender / number after lup are the original referent's; the construction
represents this as the owner `affix` with observation ∅ and agreement
read from its ancestry in O — the same owner-retention law as sup-luk in
theorum/119 §6.2, now **observable** in the output's agreement. ∎

## 3. The decision procedure

```
TADDHITA(base π, sense σ):
 1. guard     : samartha (2.1.1); π is the prathamā-named word of σ's sūtra (4.1.82 prathamāt)
 2. affix     : AFFIX(σ, π) by L1 (exceptions by list / gaṇa / phonological class: a-final 4.1.95, vṛddha 1.1.73 + 4.2.114, feminine 4.1.120, …)
 3. mode      : vā (4.1.82) unless nityam; local options between affixes (D3)
 4. markers   : its(α) → D4 (vṛddhi 7.2.117 / 118 with 7.3.3; ṭha → ika 7.3.50 / 51; 7.1.2 initials)
 5. bha ops   : D6 on the base before a vowel-initial affix (6.4.146–175), 1.4.18
 6. deletion  : luk (1.2.49) / lup (4.2.81, 1.2.51 yuktavat) when the text says so
 7. category  : D5 (gender; avyaya by 1.1.38; feminine by theorum/111)
 8. sup       : the declension engines, or none
output: the SET of licensed words (D3), with the vigraha as a licensed sentence under vā
```
