## 0. The domain in the text's own words

> 3.1.91 *dhātoḥ* ; 3.1.92 *tatropapadaṁ saptamīstham* ; 3.1.93 *kṛd atiṅ* ; 3.1.94 *vā 'sarūpo 'striyām* ; 3.1.1 *pratyayaḥ* ; 3.1.2 *paraś ca*

A kṛt is any affix of the adhikāra 3.1.91 *dhātoḥ* (to the end of 3.4)
that is not a tiṅ (3.1.93); it follows the root (3.1.2); a word standing
in the **locative** in the vidhi is the affix's *upapada* (3.1.92); and
within this adhikāra a special affix that is **not identical in form** to
the general one applies **optionally** beside it, except among the
feminine (bhāva) affixes (3.1.94). Those four clauses fix the carrier,
the upapada input, and the modal law of the whole domain.

## 1. Definitions

**D1 (the kṛt record).** `k = (ρ, α, σ, υ)` — root ρ (its upadeśa form,
theorum/86's PG-pinned entry), affix teaching form α with its markers
read by theorum/82 (`its(α, "pratyaya")`), sense σ, optional upapada υ
(a kāraka-word or an avyaya, pre-sup: theorum/119 §1). The output is a
prātipadika (1.2.46) with a gender / avyaya status (D4) — or, for the
upapada case, the compound of 2.2.19 (nitya, pre-sup).

**D5 (the modal law: vā'sarūpa).** Let `G` be the general affix for a
sense (ṇvul / tṛc by 3.1.133 for kartṛ; ghañ by 3.3.18 for bhāva; …) and
`S` a special affix taught later for a sub-domain (ac after pacādi by
3.1.134; ka after ig-upadha by 3.1.135; ṇini after an upapada by 3.2.78;
…). Then on the sub-domain:

```
if surface(S) ≠ surface(G) and the sense is not a feminine (bhāva) one:   licensed set = {S-form, G-form}      (3.1.94 vā 'sarūpaḥ)
if surface(S) = surface(G)                                               : licensed set = {S-form}              (the sarūpa exception)
if the sense is feminine (ktin / a / yuc / …, 3.3.94 ff.)                 : licensed set = {S-form}              (3.1.94 astriyām)
```

So *pācakaḥ* (ṇvul) and *pacaḥ* (ac, 3.1.134) are both licensed for the
agent of *pac*; *kartā* (tṛc) and *kāraḥ*? — no: *kāra* is ghañ (bhāva),
not an agent form; the agent pair is *kartā* / *kārakaḥ* (both general,
3.1.133 names both). The feminine action-noun *kṛtiḥ* (ktin) excludes a
ghañ feminine. This is the kṛt domain's version of theorum/118 D4 and it
is a **set-valued** output, as there.

## 2. Lemmas

**L1 (σ is decidable from the text for every certified affix).** For
each affix in the certified packets 86 / 89 / 100 / 107 the sense is the
3.4.67 default or one listed override (kta: 3.4.70 / 71 / 72 / 76; tavya:
3.4.70; lyuṭ: 3.3.115 / 117; ghañ: 3.3.18 / 19); none of them required a
declared σ. *Proof*: inspection of D2 against the packets' claim
boundaries. ∎

**L2 (the marker algebra is the sup / tiṅ marker algebra).** Every row of
D3 is a rule conditioned on a marker class (ṇit, kit, pit, ghit) or on
the ārdhadhātuka status (3.4.114 *ārdhadhātukaṁ śeṣaḥ*: every kṛt is
ārdhadhātuka except śatṛ / śānac, which are sārvadhātuka by 3.4.113
*tiṅśit* through their ś); the marker classes are computed by theorum/82's
`its` and the ārdhadhātuka status by 3.4.113 / 114 as in theorum/95 –
108. Hence a kṛt derivation is a word in the **same** event vocabulary
(ITI, GUNA / VRDDHI, SAMPRASĀRAṆA, LOPA, AUGMENT) that the verbal packets
use; nothing kṛt-specific is added to the carrier. ∎

**L3 (niṣṭhā = kit + the tripādī chain).** kta / ktavatu are kit
(1.1.26 *ktaktavatū niṣṭhā*; k it 1.3.3), so 1.1.5, 6.1.15 / 16, 6.4.37
act; the ta then meets the tripādī rules theorum/87 certified in 8.2.1
order (8.2.42 *radābhyāṁ niṣṭhāto naḥ pūrvasya ca daḥ*, 8.2.43, 8.2.44
*lvādibhyaḥ*, 8.2.45 *oditaś ca*, 8.2.51 *śuṣaḥ kaḥ*, 8.2.52 *paco vaḥ*,
8.2.57 *na dhyākhyāpṝmūrchimadām*, 8.2.58, 8.2.40 *jhaṣas tathor dho
'dhaḥ*), and the iṭ question is 7.2.10 with 7.2.14 – 17. ∎

**L4 (kṛtya = bhāva / karman + the yat / ṇyat / kyap split).** 3.4.70
fixes the sense; 3.1.97 *aco yat* (vowel-final roots), 3.1.124 *ṛhalor
ṇyat* (ṛ-final and consonant-final roots), 3.1.106 / 109 / 110 kyap (the
listed roots, with 6.1.71 tuk since kyap is pit), 3.1.96 tavyat /
tavya / anīyar (all roots) partition the roots; where two apply (ṇyat
and tavya on *kṛ*) both are licensed — they are *sarūpa*-distinct, so
D5 gives {kāryam, kartavyam, karaṇīyam, kṛtyam}. ∎

**L5 (the ku-split is a sense split).** 7.3.52 makes c / j → k / g before
ghit / ṇit / ṇyat; 7.3.66 – 69 withdraw it on named roots **in named
senses**: *vākyam* (sentence) vs *vācyam* (to be said; 7.3.67 *vaco
'śabdasaṁjñāyām*), *bhojyam* (food; 7.3.69 *bhojyaṁ bhakṣye*) vs
*bhogyam* (to be enjoyed), *yājyam* (7.3.66). So the ku event carries a
sense guard; both members of each pair are licensed, in different σ. ∎

**L6 (upapada kṛts are the pre-sup compounds).** 3.1.92 names the upapada
by its locative in the vidhi (*karmaṇi* in 3.2.1, *supi* in 3.2.4 / 3.2.78,
*divā-vibhā-…* in 3.2.21, *īṣad-duḥ-su* in 3.3.126, *stamba-karṇayoḥ* in
3.2.13, …); the kṛt-form compounds with it by 2.2.19 *upapadam atiṅ*
(nitya, pre-sup, theorum/119 §1). The compound is therefore formed **after**
the kṛt affix and **before** any sup — the order the construction records
as `KRT → UPAPADA(2.2.19) → CAT → SUP`. ∎

## 3. The decision procedure

```
KṚT(root ρ, sense σ (or ⊥), upapada υ (or ⊥)):
 1. candidates : the set of vidhi clauses in 3.1.95–3.3.130 + 3.2 whose root-list / upapada-list / sense admits (ρ, σ, υ)
                 (the lists are inputs: pacādi 3.1.134, gaṇas, uṇādi 3.3.1 bahulam)
 2. modal set  : by D5 (vā'sarūpa): general ∪ special, or special only
 3. markers    : its(α) for each affix in the set                                     (theorum/82)
 4. sense      : σ by D2 (default 3.4.67; overrides); reject the affix if σ is not admitted
 5. root ops   : D3 in the order iṭ-decision → samprasāraṇa / lopa (kit) → guṇa / vṛddhi → tuk / yuk / ku → 6.4 lopa (ghañ) ; then the tripādī (8.2.1 order) for ta-initial affixes
 6. category   : D4 ; avyaya by 1.1.39 / 40
 7. upapada    : if υ ≠ ⊥, the compound by 2.2.19 (nitya) with 6.3.67 mum / 6.3.73 nalopa etc. (theorum/119 §4.4)
 8. sup        : the declension engines, or none (avyaya)
output: the SET of licensed words, one per modal branch and per sense-guarded ku / kutva branch
```
