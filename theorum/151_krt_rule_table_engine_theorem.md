# Kṛt Rule-Table Engine I — eight kṛt affixes on every declared root, 1,537 / 1,544: the participles and verbal nouns as one ordered table

3 November 2026. The kṛt affixes make the prātipadika the nominal engine declines; theorum/100 and theorum/107 built a few of them on a handful of roots. This packet writes the first kṛt table: eight affixes — the niṣṭhā kta and ktavatu (3.2.102 *niṣṭhā*, 1.1.26), tavya and anīyar (3.1.96 *tavyattavyānīyaraḥ*), tumun (3.3.10), ktvā (3.4.21 *samānakartṛkayoḥ pūrvakāle*), tṛc and ṇvul (3.1.133 *ṇvultṛcau*) — on all 193 roots the verbal engine declares, as 72 rows over a three-segment state (root | iṭ | affix), read against the independent generator's 1,544 cells (`research/independent_oracle/VIDYUT_KRT_LANE.json`, a new lane of the earlier lanes' grade). The table agrees on 1,537; the seven left are named.

The design is the verbal engine's: the kṛt affix is ārdhadhātuka (3.4.114), kit or not (1.1.5 *kṅiti ca*; 1.2.18 *na ktvā seṭ*; 1.2.19 *niṣṭhā śīṅsvidimidikṣvididhṛṣaḥ*; 1.2.8; 1.2.26's option), ṇit for ṇvul; what the root does before it is a row of the sūtra that says so. The aṅga rows the verbal table already has are written again here over the smaller state (7.2.35, 7.3.84 / 7.3.86, 7.2.115 / 7.2.116, 7.1.100 / 7.1.102 / 8.2.77, 6.1.15 / 6.1.16, 6.4.37, the tripādī): the kernel lists them as shared and the capsule says plainly that they are the one sūtra written twice — the next packet folds the kṛt affixes into the verbal table as a lakāra-like mode, so that the restatement disappears.
