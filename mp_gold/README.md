# MP Gold Mine

This folder is the salvage tray for useful MP results that are not part of the terminal `theorum/` chain but are too valuable to lose before MP is retired as an active working repository.

Rule of use:

```text
theorum/  = terminal theorem capsules for the RH endpoint route
mp_gold/  = reusable foundations, methods, warnings and proof machinery mined from MP
```

Nothing here should be treated as a new RH terminal claim. This is clean reusable metal from the workshop floor, not the crown jewel itself. Humans do love mixing those up, usually right before disaster and a grant application.

2. `02_x3_channel_no_escape.md`

5. `05_curvature_to_seam_index.md`

6. `06_unified_seam_block_krylov.md`

7. `gold_manifest.json`  
   Machine-readable source PR list and transfer status.

## Policy

MP should not be used for new theorem development after this migration. Future work should happen in RKF. MP remains only a source archive until its useful parts have been copied, summarized, or intentionally discarded.
