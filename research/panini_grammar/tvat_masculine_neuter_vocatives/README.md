# PG899 · Masculine and neuter *tvat* vocatives

Monty · 26 November 2026

assigns the remainder to `marut`; it separately assigns neuter `tvat` to
`jagat`. The named pattern address rows therefore supply masculine
`tvat/tvatau/tvataḥ` and neuter `tvat/tvatī/tvanti`.

unambiguous panel, all three feminine address keys remain Open rather than
