## D1. Domain and distinct causes

A new admitted history has one exact lexical ID from H01, listed meaning,
kartari laṭ, contextual P/A admission, person/number, selected classical
register, and the N/G source policy. The record distinguishes the deleted
teaching u₀, pronounced affix u₁, root ṛ₀, root nasal and tiṅ markers.
An operation is addressed by **target occurrence, conditioning occurrence,
source rule/policy and current history**, not by a global strong/weak bit.

For the G root event the target is ṛ₀ and the nimitta is u₁. For the
affix grade the target is u₁ and the nimitta is the tiṅ. Thus the same
history can license root grade and refuse affix grade. The fact that the
tiṅ is ṅitvat never retargets the first event's nimitta. Missing source or
context gives OPEN; a failed necessary condition gives BLOCKED. Neither
status is silently reclassified as an admitted alternative.

## D2. Branches form a relation with a history-dependent fibre

Let N/G be the two admitted root policies and R/L retain/delete u₁.
For each H05 m/v cell the subsequent deletion choice has domain

\[
F(N)=\{R,L\},\qquad F(G)=\{R\},\qquad
\mathcal R=\{(N,R),(N,L),(G,R)\}.
\]

The relation is constructed after grading; it is a three-element subset
of the four-element product, with the rejected (G,L) request retained in
the complementary channel. The changed predicate is actual rṇ adjacency
before u₁. H04 is a different consumer: its yaṇ request is not a request
for L, so G does not block it. This proves the stated dependency on the
finite admitted histories; it is not a proof that all Sanskrit options
share this particular relation.

The ordinary zero-reading retains these source and owner distinctions.
For contrast, let q forget the policy in two pre-grade histories with
the same pronounced tṛṇ + u + tip. Then q(h_N) = q(h_G), while the
selected root-grade event is absent in h_N and present in h_G. A function
of that policy-erasing q alone cannot recover the selected event on both.
This is a bounded information-loss observation. It does not rule out a
set-valued grammar operating with the two source policies still supplied.

## N2. Typed zero compatibility and pairing

Let ε be the inherited empty-word dagger homomorphism from B₅₉ to CΣ,
and let π₀ apply it coefficientwise while keeping history and channel
addresses. On the declared finite domain,

\[
\pi_{0,\mathrm{out}}\operatorname{Construct}_{59,\lambda}
=\operatorname{Construct}_{59,0}\pi_{0,\mathrm{in}},
\qquad
\epsilon\langle x,y\rangle_{B_{59}}
=\langle\pi_0x,\pi_0y\rangle_{C_\Sigma}.
\]

The cuts choose the same histories before and after ε, and
ε(1 + z_e) = 1 for every legal event. The homomorphism preserves the
finite branch sums and typed compositions; these facts prove the first
identity by induction over H01–H05. Scalar extension and the dagger
homomorphism give the pairing identity. Unit-start histories recover
the 120 listed policy-labelled branches in 54 inherited positions.
For arbitrary signed input sums, cancellation can occur; branch counting
is not asserted to be invariant under such cancellations.

The branching maps need not be isometries. Event order supplies an
ordered history, not a calibrated physical clock. This stage adds no
physical quantum gate, universal compiler-soundness or hallucination-free
claim. General source arbitration, lexical/register coverage and runtime
integration remain open; the canonical operator engine is unchanged.
