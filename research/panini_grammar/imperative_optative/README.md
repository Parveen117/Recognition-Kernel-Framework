# PG19 — Loṭ and vidhiliṅ from intended meaning to owned words

Author: Monty. 2 November 2026.

PG19 constructs a finite classical **imperative/optative** domain on the
native grammar carrier. Loṭ and vidhiliṅ share several intended meanings;
the discourse context selects a relation of admissible moods. Their endings
then change the actual stem conditions. Copying laṭ endings or assigning
one permanently strong/weak stem cannot derive the new words.

The written domain has **976 morphological positions/readings**: 108
nine-slot paradigms and four Bhāva single-slot entries. It covers ten basic
kartari roots, thirteen causal frames, four basic karmaṇi stems, two Bhāva
stems and all thirteen causal karmaṇi stems. Counts factor out distinct
semantic witnesses producing the same morphology. No new grammar execution
or whole-Sanskrit completion percentage is claimed.

## Boundary

This is non-Vedic, unaccented, unprefixed, non-doubling internal morphology
with the declared pause convention. Āśīrliṅ, blessing loṭ/tātaṅ,
prohibitive māṅ, the other liṅ senses, san/yaṅ, nested causatives,
karmakartṛ, reciprocal uses and general sentence interpretation remain
outside. The finite semantic layer includes kṛtya alternatives as external
obligations where the source names them; it does not construct those words.

Grammar, navigation and engine tests and certificate replay remain deferred
under the owner's mathematics-first instruction. The shared engine and
PG1–PG18 evidence are unchanged. These are written source-relative proofs,
not a new runtime or proof-assistant formalization.
