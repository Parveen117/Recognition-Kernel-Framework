can carry the expressed object's karman edge, while the source explicitly
leaves that objecthood unselected for han. A separate own-chest analysis
instead binds chest to the actor and uses the svāṅga vārttika. These are
competing retained histories, not simultaneous facts about one parse.
An unselected interpretation remains Open. None is selected merely by
recognizing the printed word.
