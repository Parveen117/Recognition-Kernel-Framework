# PG14 — Meaning, voice and the grammar operator construction

Author: Monty. 2 November 2026.

PG14 develops the grammar in writing before another implementation batch.
It connects an explicitly interpreted event to kāraka assignments, the role
expressed by tiṅ, pada, person/number, affix ownership and a word derivation.
It also constructs a native cut-field operator model retaining ordered
grammar history and proves its typed zero-specialization law.

The immediate linguistic addition is a closed **decision relation on the
declared semantic domains**, not a natural-language meaning parser. The
causative domain uses the twelve lexical identities of PG13 and derives its
formation and pada permissions from a frame, replacing the need for an
unexplained permission Boolean in that written model. It includes optional
causee case and optional pada as independently recorded choices. The passive
chapter distinguishes karma-prayoga from bhāva-prayoga and derives all nine
thematic A endings where the expressed participant licenses them.

## What is established here

1. A sound composition theorem relative to explicitly supplied local
   grammatical relations, with a separate condition for completeness.
2. A total voice/pada decision on the completed frames in the stated domains;
   incomplete frames yield named obligations. In bhāva, the agent's number
   and person do not select the tiṅ ending.
3. Written thematic A formation, including causative A forms and ṛ-final
   yak passives absent from the reviewed T110 packet.
4. An algebraic full-operator-family instance with a proved specialization
   to the same **history-bearing** classical grammar. Its residue generators
   are not a scalar lambda parameter and are not erased source records.

These results do not establish full Aṣṭādhyāyī completeness. The native
construction is an admitted model, not a proof that every native operator
algebra has the required augmentation or that all existing Python adapters
already realize it. The shared engine remains in `operator_foundation/`.
There is no second engine, new runtime or new certificate in this packet.

PG1–PG13 and the historical theorem packets are frozen. Their numerical
coverage is unchanged: 228 simple-present root entries / 2,610 cells, with
108 separately counted causative P cells. Written PG14 derivations do not
silently add to these implementation counts.
