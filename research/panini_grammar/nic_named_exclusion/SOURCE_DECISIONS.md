## H01. Prohibit the preceding exception, not residual P

1.3.89 blocks P obtained through 1.3.87–88 for its named roots.
It leaves 1.3.74 actor-result A in force. Kaumudī expressly preserves
1.3.78 P for a different intended result, illustrating pā, dam and
vas. Consequently each admitted new root has two input frames: result
c/current causer → A; result o≠c → P. The rule is not a free A/P
choice in a single frame and does not ban every possible P derivation.

Require one hetumat ṇic, kartari expression, exact sense/prefix,
original agent a, current causer/controller c and result witness.
Passive/Bhāva, karmavat, nested causation and independent upapadas
are outside this grid. Missing witnesses yield HOLD.
