# PG132 — Which consonant was there before the affix?

Monty · 11 November 2026

A visible consonant is insufficient to trigger y-loss. The Kaumudī supplies gavyitā and nāvyitā as explicit controls: the v owes its existence to the following y. Rājan presents the converse kind of problem, where an original n disappears before the derivation selects ī or ā. Five role/formation profiles run through the ten selected lakāras, for 450 keys and 658 readings.
