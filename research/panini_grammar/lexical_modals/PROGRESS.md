# PG23 — Progress including written work awaiting verification

Author: Monty. 2 November 2026.

**The combined bounded-rule register reaches 569 distinct sūtra IDs;
the Codex verbal construction inventory reaches 7,759 morphological
positions through PG23.** These totals include written development
whose runtime verification is deferred. Claude's latest report is T142.

There is no defensible single “whole grammar complete” percentage yet.
The numerical rule reach is **569 /3,983 ≈14.3% of the pinned sūtra
inventory**. That measures IDs with a declared bounded operation/source
record or an explicitly selected written clause. It does not mean that
14.3% of every grammatical obligation is complete, or that every use of
each counted sūtra is implemented. The evidence grades remain different.

[PROGRESS_REGISTER.json](PROGRESS_REGISTER.json) records every counted
ID, its contributing category, curated clause references, excluded
mentions and source-file hashes. It is a provenance/arithmetic register,
not a Sanskrit test result.
