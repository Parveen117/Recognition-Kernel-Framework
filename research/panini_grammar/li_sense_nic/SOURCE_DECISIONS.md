## H01. Two admitted lexical entries; the curādi homonym is separate

Kāśikā/Nyāsa 1.3.70 and 6.1.51 expressly take both divādi
līṅ `1040034` and kryādi lī `1090036`, śleṣa. Their basic
pada/vikaraṇa differences do not block this ṇyanta rule. Nyāsa's
argument uses their shared meaning and derived śap configuration;
it does not authorize erasing the lexical ID from the history.

Curādi lī `1100343`, dravīkaraṇa with optional lexical ṇic,
is archived but excluded. No such lexical ṇic or nested causation
is silently imported. The counted input is one source-qualified
current ṇyanta in kartari; deriving arbitrary semantic analyses
from a bare dictionary gloss remains an open obligation.

## H02. Three positive A frames under 1.3.70

Each of the two admitted roots has three independently keyed frames:

| Frame | Prefix | Source role certificate |
| --- | --- | --- |
| SAṂMĀNANA | ā | Controller c receives honour; jaṭā j is the causal instrumental; no expressed current object is invented. |
| ŚĀLINĪKARAṆA | ud | Controller c overpowers current object q, as śyena/vartikā. |
| PRALAMBHANA | ud | Controller c deceives current object q. |

Kāśikā reads saṃmānana as pūjana, śālinīkaraṇa as
nyagbhāvana, and imports pralambhana by ca. Nyāsa explains
abhībhavana and the causal instrumental in jaṭābhir ālāpayate.
The honour example means obtaining honour; it is not evidence
that the current controller is a karmavat grammatical object.
The present register keeps this source-specific semantic analysis,
without fabricating a uniform lower-agent/causer map for all senses.

These are special A licenses, including the commentary's
akartṛ-abhiprāya scope. The principal-result recipient is not
used as an admission test here; the honour reading is not forced
into an other-recipient story. Current voice stays kartari.
Karmavat, ciṇvat, passive yak and a second ṇic are excluded.

## H03. Positive ordinary P control and bounded inventory

For each lexical entry add the source's bālakam ullāpayati
control, with ud, current controller c and expressed object q.
It has an independently supplied ordinary, non-honour,
non-overpowering, non-deception certificate and other-directed
principal result. Rule 1.3.78 then licenses P; 1.3.74's
actor-result A is outside that selected request.

A missing named-sense witness does not automatically prove this
positive P frame. Unknown sense/roles stay HOLD. The same bāla
object can occur in the deceptive A example, so the object noun
alone cannot decide pada. The eight profiles combine two lexical
IDs with four explicitly admitted source frames, not arbitrary
new senses or automatically crossed prefixes.

## H04. Vyavasthita-vibhāṣā and correlated root branches

Rule 6.1.51's ā option is distributed by context. Kāśikā
1.3.70 states that it is mandatory in these named senses and
optional elsewhere; Kaumudī 7.3.39's vārttika explicitly lists
pralambhana, abhibhava and pūjā. Thus all six named A profiles
have only ā plus 7.3.36 puk, **lāp**. Each ordinary P profile
has two branches: ā/puk **lāp**, or retained ī with 7.2.115
vṛddhi and 6.1.78 āy, **lāy**. The latter root-owned y is
separate from the later ṇic ay.

Both lexical entries qualify. Līyate in 6.1.51 is the shared
yak designation, not a restriction to the divādi śyan stem.
The root decision belongs to the ṇic environment and persists
when a later operation removes ṇic. All eight current profiles
exclude sneha-vipātana; 7.3.39's nuk/luk alternatives therefore
supply no līn/lāl branches here. An ordinary counterexample is
not a licence to multiply all root augments indiscriminately.
