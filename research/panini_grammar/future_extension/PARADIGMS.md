# PG17 — Explicit nine-slot expansion of every admitted branch

Author: Monty. 2 November 2026.

This register gives **79 fully specified branch rows**. Each row selects
one of the following exact nine-component tuples and supplies its only
string argument. Thus all **711 morphological branch readings** are
specified without a repeated list of 711 independently asserted words.
The factorization is justified by R8 and C7; it is not an unproved
suffix lookup. Source quotation, derivation and execution remain separate.

## P4. Coverage accounting and the construction theorem

Basic positions before expanding iṭ choices are 234; their 37 branch
rows give 37·9=333 morphological readings. Causatives have 21 pada
profiles and two futures, giving 42·9=378 positions/readings. Hence

\[
 234+378=612\quad\text{positions},\qquad
 (37+42)\,9=711\quad\text{branch readings}.
\]

These totals do not count the same word as a new unique string merely
because its profile differs. They deliberately retain different profile
positions even when a readout is equal. Distinct causal role witnesses
with the same morphology are retained in native history but not added
again to this morphological register. No old executable count is changed.

**Theorem P4.** Relative to the declared lexical, semantic, source and
phonetic policies, every entry of every tuple in P2/P3 has a licensed
owned derivation, and every morphological branch in B4/C2 is represented.
Native specialization recovers exactly the same labelled derivations.

**Proof.** B6 exhausts basic joint choices, and P2 lists their twenty
lṛṭ plus seventeen luṭ rows. R8 proves their nine-slot extension.
C7 gives the twenty-one causal pada profiles in each future and P3
lists them. P1 supplies exactly the nine original ending positions in
each case. PG14's composition theorem retains the witnesses; N3 gives
exact typed zero-recovery. Conversely, any admitted branch must first
choose a row of B4 or C2 and then one of the nine endings, so it occurs
in the register. □

This is a written factorization proof, not an independently executed
711-case experiment or a proof of all future Sanskrit beyond this domain.
