## Scope of completion

The basic roots are svṛ, class-5 dhūñ, class-6 iṣ in the sense of
desire, nṛt, and the five exact vṛt-group entries vṛt/vṛdh/śṛdh/syand/kṛp.
Iṣ's lexical **icchā** sense is distinguished from a san formation,
which is not included. The causatives reuse PG14's twelve completed
causal domains and their 21 admitted root/pada profiles.

All forms are classical, unprefixed, unaccented kartari forms in pause.

remain in force. Optional consonant doubling is not expanded; for the
syand aniṭ luṭ junction, the licensed single-t option of 8.4.65 is
selected explicitly. Wider root inventories, prefixes, nested causatives,
desideratives/intensives, bhāva/karma futures, sat participles, lṛṅ and
unrestricted parsing remain open.

No Python grammar/navigation tests, certificate replay, software oracle
comparison or shared-engine suite was run. The owner's mathematics-first
instruction remains active. Historical implementation counts, PG1–PG16
