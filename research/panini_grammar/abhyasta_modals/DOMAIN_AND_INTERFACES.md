construction is added. Use the inherited non-doubling, devoiced-pause
policy, retaining any collapse that actually meets its source conditions.

## D3. Ending state supplied to every family

The I/B ordinary P 3sg and all first persons in both padas are strong;
3.4.92 supplies pit with first-person āṭ. Ordinary hi is apit.
Other ordinary slots are weak. Every O ending is weak by the inherited
effective-marker account. Whole tātaṅ is separately ṅit/weak.

All fifteen roots are abhyasta on this domain. Thus 7.1.4 gives
the actual **at** replacement of jh before the root query, for P
ordinary 3pl **atu** and A ordinary 3pl **atām**. No n is inserted
into those endings. This lexical designation does not create a copy
owner for the three class-2 roots.

O P's actual root-facing material begins with y, including 3pl yus.
O A follows the inherited resolved-augment view: after the admitted
s-lopa its actual first sound is ī. The source-qualified ā-lopa
choice for māṅ/hāṅ is specified in M3. A bare ending behind a
surviving augment is not the root's next sound.

## D4. Typed family interface

Each row supplies the following interface to the common ending and
sound constructors. Missing or conflicting interface evidence is Open.

| Field | Meaning |
|---|---|
| lexical key | exact entry, sense, register and qualified pada |
| copy status | owned ślu copy or lexical abhyasta without a copy |
| copy map | source-conditioned shortened/guṇa/i copy and its retained deletions |
| vowel query | final ik versus light upadhā; strong/weak; lexical exception |
| next context | actual vowel, y, other hal, hi, or selected tāt |
| choice fibre | the finite alternatives after those conditions are resolved |
| readout family | vowel seam, ur-lengthening, palatal/retroflex contact, or s-lopa |

The interface is not just a current stem string. In particular
abhyasta+pit+vowel does not by itself say whether 7.3.87 blocks guṇa,
and hā+hi does not select hāk versus hāṅ.
