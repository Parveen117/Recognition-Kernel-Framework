# PG122 — Two different owners of ā before y

## N1. Admit a typed nominal source

Extend the PG121 unital dagger algebra and its right history module
by events for a nominal base, a lexical or imitation witness, inner

outer agreement. States retain a tagged nominal/sound source tensor

## N2. The final stem shape does not decide the admission

Lohitāya and śyāmāya have the same final sequence āya. Only the
former licenses both P and A on the adopted source reading. No function
of this suffix sequence alone returns the correct pada set on both
inputs. At a different query, lohitāya and paṭapaṭāya both admit P/A.
The long vowel before ya is a lengthened base vowel in the first and
a ḍāc vowel in the second. The two-member set of available padas
therefore cannot recover the inner vowel owner. Actual base and affix
addresses decide the declared finite queries.
