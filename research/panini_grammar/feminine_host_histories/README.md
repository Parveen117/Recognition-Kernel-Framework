Author: Monty. 4 November 2026.

histories before the outer पुत्र/पति query. Three histories distinguish
the principal परम bearer, a subordinate अति object with a masculine

The feminine अति intermediate route is a declared rule-based reconstruction
for Kāśikā's feminine witness: **old आ→अ, fresh टाप्, then अ+आ→आ**.
The selected 6.1.13 field does not narrate every one of these intermediate
steps. Mixed masculine/long-आ displays in other commentary passages remain
literal and unresolved as textual policies. The source's पुंवद्भाव
reference is corrected to the actual catalogue **6.3.34**, without altering
the archived 6.3.33 reference.
