## Common realization conventions

The input supplies the feminine meaning, lexical entry, applicable authority,
non-subordinate use and decisive exclusions. A descent history additionally
supplies its actual affix origin, relation to the ancestor and the non-ऋषि
condition. These are grammatical annotations, not inferred identities of
present-day people. Unknown required evidence returns OPEN.

Each base has an address `b`; each introduced affix has a different address
`f`. An inner-affix replacement changes `f`'s active value and retains its
origin, prescription and removed markers. An outer feminine suffix has a
fresh address `g`. Deletion in these histories changes an addressed active
segment; it does not remove the record that supported the earlier action.
Every later query uses the current relevant view and the appropriate retained
cause. It does not reuse a stale admission simply because a spelling matches.

Here `ṅīp → ī`, `ṣyaṅ → ya`, and `cāp → ā` are marker projections:
1.3.3/6/7/8 with 1.3.9 give the applicable exclusions from spoken material.
The letters of य include its inherent अ. A display such as `वाराह् | य`
therefore reads वाराह्य before the outer feminine vowel is introduced.

For 4.1.38 the admitted branch family is exactly

\[
J_{38}(q)=\{(\mathrm{au},\mathrm{ṅīp}),
(\mathrm{ai},\mathrm{ṅīp}),(\varnothing,\varnothing)\}.
\]

The source assigns उदात्त to the substituted vowel. No independent choice
of ङीप् is admitted after selecting neither substitution. These are grammatical
alternatives under one adopted source policy, not conflicting editions.
Full accent propagation remains a named obligation below.

## D03 — Neither substitution also means no ङीप्

**Given state.** The same qualified मनु input selects

## D05 — आर्तभागी does not turn an अञ् into an अण्

**Source:** Kāśikā/Nyāsa 4.1.78; Kāśikā 4.1.104/73/15/63,
Kaumudī 4.1.73; Kāśikā 1.4.18, 6.4.148 and the marker rules.

**Given state.** Start from the source's already admitted आर्तभाग base
with the explicit ancestry `ऋतभाग + अञ्` under the बिदादि prescription.
The historical derivation of that input is supplied here, not newly proved
from a bare word. Its गोत्र/जाति reading and heavy penultimate are supplied.

1. The 4.1.78 origin query reads `f.origin = अञ्`. The required membership
   in `{अण्, इञ्}` is false. Return BLOCKED for ष्यङ् even though the
   phonological and other stipulated conditions match.
2. Requery the appropriate feminine prescription for the actual अञ्-ended,
   जाति-bearing base. Under Nyāsa's explicit correction, 4.1.73 supplies
   `g = ङीन्`. It is not an untyped “ई suffix.”
3. Project the markers of ङीन् to ई. In the qualified भ view, 6.4.148
   deletes the preceding final अ, giving **आर्तभागी** from this admitted
   base. Preserve the ङीन् source despite identical unaccented ई outcomes
   from other feminine suffixes.

**Result:** BLOCKED for 4.1.78 and APPLIED for the declared corrected
feminine continuation. Kāśikā's 4.1.78 sentence labels its control ङीप्;
Nyāsa calls that a textual lapse and explicitly substitutes ङीन् under 73.
The raw field remains unchanged. **Downstream obligations:** full input
derivation if it is not supplied, accent, and any requested declined form.

## D07 — औडुलोम्या requires the earlier टि deletion

**Source:** Nyāsa 4.1.78; Kāśikā 4.1.96, 1.1.64, 6.4.144/168,
7.2.117, 1.4.18, 4.1.74 and 6.1.101; Kaumudī 6.4.144/168.

**Given state.** Use Nyāsa's admitted उडुलोमन् example, with its supplied

|Step|Current query and addressed event|Active display|

|3|Recompute the whole-base 4.1.78 gate: the penultimate syllable लो is now heavy|The heaviness evidence belongs to this post-टि-lopa view|
|4|Only now replace the original inner इञ् token by ष्यङ्|औडुलोम् + य → औडुलोम्य|
|5|Add outer चाप् under 4.1.74; apply the local अ/आ junction under 6.1.101|औडुलोम्या|

**Why reversing the order is not admitted.** Before the टि deletion, the
pre-final syllable of the इञ्-attached expression does not supply the required
heavy penultimate. Nyāsa therefore requires टि-lopa first. Introducing
य-initial ष्यङ् prematurely would additionally raise the 6.4.168 प्रकृतिभाव
obstruction to deleting अन् in the non-भाव/कर्म domain. Neither obstacle
can be repaired by borrowing a later state's heaviness or by rewriting the
already recorded event order. Once the actual earlier deletion has occurred,
the later य does not restore the inactive अन्.

**Result:** APPLIED for this source-qualified ordered unaccented stem
history; BLOCKED for the premature ष्यङ् plan. The source prints the stem
inside औडुलोम्येति; the separated feminine readout is औडुलोम्या.
**Downstream obligations:** lexical admission beyond this supplied witness,
accent, inflection, and broader interaction/termination analysis. The local
ordered history does not prove a global scheduler correct.
