# Domain and specialization

## N1. Ordered carrier

Extend PG141 with an outer y-retention/loss arrow after the source-specific lexical s decision, then the addressed iṭ and ending/auxiliary arrows. Store the pre-y sound as a derived fact of the inner result and retain the root of each decision.

## N2. Branch dependence

A pair of Booleans with independent truth values would admit the fourth combination on payas. The admissible set is a typed dependent sum: for lost s select retained y only, and for retained final s select either y history. For internal s there is no lexical s-loss decision.

## N3. Zero-reading

For each source policy filter inner histories first. The ordinary projection of the remaining suffix, sound and auxiliary paths gives exactly the selected endings. Each output has the corresponding ordered path in the written relation. Support union over policies is explicit; it does not make every path of the union available inside each policy. Finite incidence gives its converse with full provenance.
