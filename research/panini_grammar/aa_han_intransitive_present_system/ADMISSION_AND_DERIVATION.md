## 2. Why the morphology can be reused

After admission, each of the 36 requests has the same root, prefix order,
voice, A-ending sequence and sound/marker visibility as its explicitly pinned
PG323/324 morphological control. The intervening operations below do not
query whether A admission came from akarmaka or the own-limb vārttika.
This is a restricted dependency claim for these operations, not a global
assertion that semantic frames never affect Sanskrit morphology.

Project a retained state to its owned-sound and ending/visibility tuple q.

q(f(h)) = f_shape(q(h)). Induct over the displayed finite event list. Thus

object or svāṅga admission into it. This is not a licensed map from an

## 4. Full operator/history construction before zero-reading

Use PG14 N1–N5's native cut field C with derived iota and dagger, free
cut-path coefficient algebra B = C⟨z_e,z_e*⟩ and history-graded right module
M_lambda = ⊕_h e_h B. Pair by ⟨x,y⟩_B = Σ_h x_h* y_h. Here lambda names
this operator construction, not elapsed time or a scalar table parameter.
Extend its event labels with the intransitive admission and the finite
owned-sound operations above. Each new h retains source, complementary
channels, semantic frame, old/new sounds, owners and ordered evidence.
An event changes the actual state and acts by

    T_e,lambda(e_h a) = e_h' (1+z_e)a.

True, false and unknown admission histories have disjoint cuts P_A, P_X,
P_O summing to identity on the declared input domain. Keep Q_A=1−P_A;
object-bearing histories are excluded from this relation, not declared
ungrammatical in every other relation. Unknown histories never enter the
accepted channel just by matching a printed word. Subsequent guards inspect
retained grammar state, not residue coefficients. The semantic label is
never quotiented out by the shape projection q used in the proof above.

Let epsilon:B→C take the empty-word coefficient. Let pi_0,M act on state
coefficients and Pi_0,op on typed operator entries. For every new edge,

    pi_0,M(T_e,lambda(e_h a))
      = e_h' epsilon((1+z_e)a)
      = e_h' epsilon(a)
      = T_e,0(pi_0,M(e_h a)).

Because epsilon is a dagger algebra homomorphism, this identity extends to
the displayed finite typed compositions, cuts, complementary channels,
adjoints and pairing. Every admitted zero-level labelled derivation has
exactly the same lifted events and guards; its product of (1+z_e) has
empty coefficient 1. Conversely specialization creates no new event or
admission. This proves exact labelled finite-branch recovery on this domain.
Zero-reading retains the intransitive-versus-own-limb distinction even when
the word shape is identical. It does not reverse lopa, derive a physical
clock, prove all Sanskrit complete or supply a runtime implementation.
