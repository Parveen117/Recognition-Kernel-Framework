# Direct changed-document checks

The check uses an explicitly asserted Python 3.12 runtime. Scope: 36 unique
intransitive keys, 3 inherited/33 new credits, exact 3-word Kāśikā context,
source bytes and dependency hashes, equality to pinned word-shape controls,
row/table consistency, cumulative arithmetic, Unicode and changed local links.
The script reads documents; it does not derive Sanskrit, execute the grammar,
run predecessor suites or replay certificates. The root navigation suite and
engine verification remain deferred under the owner's written-work policy.
See DOCUMENT_CHECK_RESULT.json for the observed result.
