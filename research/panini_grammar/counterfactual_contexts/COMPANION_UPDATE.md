## Concrete source corrections and limits

1. **Ṭit/kit are reversed in the catalogue prose.** Primary 1.1.46
   gives ṭit at the beginning and kit at the end. T150's ĀGAMA-ĀDI
   description says kit, while ĀGAMA-ANTA says ṭit; examples such as
   aṭ/āṭ and puk/sak make the mismatch visible. Correct those
   descriptions before treating them as source-faithful addressing modes.
2. **A change-shape category is not a grammatical owner certificate.**
   classify() returns PRATYAYA for any newly nonempty segment except ab,
   including the initial ag segment for aṭ. The same catalogue knowingly
   files 3.4.79's ending i→e as GUṆA. Keep this coarse observation
   separate from the actual rule, owner and named grammatical operation.
   PG31 E3's conditional A1sg uses a different source path despite final e.
3. **The observation boundary is narrower than every guard call.**
   The verbal HOOK is emitted only when its aggregate (form,flags,pit)
   changes; the nominal driver uses its own aggregate. A segment-only
   redistribution preserving that aggregate is not observed by that gate.
   The lane runners also catch exceptions without an error-count channel.
   State the scope as observed successful transitions, or add those missing
   channels before claiming exhaustive execution coverage.
4. **Distinguish the bound checked from the bound reported.**
   MAX_OPS and the certificate condition allow four operations; the theorem
   reports that the observed maximum was two. The closed catalogue uses
   catch-all ĀDEŚA, so complete categorization alone is not proof that
   every label is the exact Pāṇinian construction. The module correctly
   leaves universal confluence and unique grammatical interpretation open.

These are static source findings, not new failed tests. T150's schedule
inventory is useful for locating visibility obligations, but co-firing
statistics do not prove that a reordered pair commutes.
