# PG33 — Conditional bhāva and karma with owned ciṇvat branches

Author: Monty. 4 November 2026, Asia/Calcutta.

This stage extends PG18's basic and causal voice construction to admitted
lṛṅ requests, using PG31's conditional endings and contextual admission.
It adds **229 written positions /448 branch readings**. Cumulative written
finite positions reach **11,522**. All new words are specified by the
explicit nine-component tuple and complete branch arguments in the register;
the bhāva words are individually printed. No grammar engine was run.
