# PG694 · Exact base and derived case fibres

Read the base column with body *kuṭilik*
and the derivative columns with *kauṭilik*.
The body ends before each listed tail. For
the two ablative singular masculine variants
use each tail at the same key. The base's
instrumental singular *kuṭilikayā* is also
the supporting case used in the source frame.
The derived case table indexes only one
masculine word-position per case and number.
Deer, hunter and smith remain separate
histories at its surface.
