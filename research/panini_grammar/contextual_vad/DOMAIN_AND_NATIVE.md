## N1. Full carrier and typed event domains

Start from the exact PG80 unital dagger algebra, finite-support right module,
retained role types and pairing. For the new semantic, participant, scope,
option, affix and prefix-junction events D, declare

\[
B_{81}=B_{80}\langle z_d,z_d^*:d\in D\rangle,\qquad
M_{81,\lambda}=(M_{80,\lambda}\otimes_{B_{80}}B_{81})
\oplus\bigoplus_{h\in H_{81}}e_hB_{81}.
\]

The primitive assumptions are this unital dagger extension, finite support,
and inherited module/role actions. Extend the pairing by
\(\langle x\otimes b,y\otimes c\rangle=b^*\langle x,y\rangle c\), with
orthogonal coordinate dagger pairing on the new summands. Lambda denotes
the operator carrier, not a scalar, physical clock, derivative order or
primitive Hilbert space. No dimensional constant or physical law is selected.

Each input includes exact lexical/upadeśa identity, actual ordered prefixes
and kriyāyoga, source policy, voice, meaning, role frame, participant class,
event relation and schedule, lakāra context, agreement, selected pada,
affix/marker recipients and ordered Smriti. Role frames are finite supplied
tensors: agent with topic/content for P1; agent with recipients for P2;
multiple agents with topic and differing-view relation for P3; multiple
agents with a joint-utterance relation for P4; agent with comparison party
and similarity relation but no karman for P5; and multiple agents with
jointness and incompatible-assertion relation for P6/P7. These are explicit
adapters of the inherited role carrier, not roles inferred from printed cases.

The six-slot cuts are restrictions on the supplied agreement/participant
requests, not universal linguistic exclusions. H01–H06 intersect the lexical,
role, event and source domains before H07–H10 construct words. Missing
premises produce HOLD; failed selected guards produce EXCLUDED with addresses.
These complementary channels retain their history and no word output.

## N2. Local scope and a participant-erasure obstruction

For an admitted elementary event set
\(U_d(e_hb)=e_{h'}(1+z_d)b\), where h′ appends source, guard, recipient and
stage. Complementary status transitions have coefficient 1. The P/A option
is a labelled pair of admitted branches, not a single untyped replacement.
Counting each selected pada as its own position agrees with the table keys;
where luṭ third-person strings coincide, these labels are still distinct.

The anuvṛtti query is rule-addressed: 1.3.48 retains joint utterance;
1.3.49 drops that condition but retains the participant condition;
1.3.50 reuses joint utterance from 1.3.48 under the selected source policy.
It is not a global mutable flag that stays false after 1.3.49. The conflicting
Tattvabodhinī classification is a separately retained source tag with an open
comparison obligation, not an unlabelled new branch in the counted words.

Let Q retain lexical vad and its vyaktāyāṃ vāci gloss, prefixes sam+pra,
joint utterance and 3pl, but erase participant class. The source's supplied
human joint-speaking request yields **saṃpravadante**; its ordinary bird
control yields **saṃpravadanti**, with the other A licences absent in that
control. Q agrees on these two requests while the pada outcomes differ.
Hence no decision function of Q alone can recover both outcomes. Retaining
the participant cut resolves this bounded witness. The bird control has zero
position credit and makes no modern claim about animal cognition. No general
minimal-memory or complete Sanskrit classifier theorem follows.

Evolution is finite ordered composition of these addressed events. Prefix
chains, the root-facing iṭ query and ending substitutions retain different
recipients even when the observer reads one word. Elapsed time would require
an explicit clock adapter; neither event count nor tower depth supplies it.

## N3. Typed zero and pairing compatibility

Extend the inherited dagger specialization \(\epsilon:B_{81}\to C_\Sigma\)
by \(\epsilon(z_d)=\epsilon(z_d^*)=0\). The input/output coefficient maps
retain every lexical, participant, role, prefix, event, source-policy, pada,
affix/recipient, status and ordered-history tag. Thus each selected guard
has the same truth value in its full and specialized domains. Unlike Q,
zero-specialization does not erase participant information.

For a generator event, \(\epsilon((1+z_d)b)=\epsilon(b)\); the successor
label h′ is identical on both routes. The coefficient-1 complementary
transitions satisfy the same identity. Right-linearity, labelled branch sums
and induction over finite ordered composition therefore prove

\[
\pi_{0,out}\operatorname{Construct}_{81,\lambda}
=\operatorname{Construct}_{81,0}\pi_{0,in}.
\]

On inherited extended tensors the pairing identity follows from the dagger
homomorphism and the inherited identity; on new coordinates it follows from
\(\epsilon(b^*c)=\epsilon(b)^*\epsilon(c)\). Orthogonal sums give

\[
\epsilon(\langle x,y\rangle_{B_{81}})
=\langle\pi_0x,\pi_0y\rangle_{C_\Sigma}.
\]

This is pairing compatibility, not isometry of every event operator. The
unit-start word observer recovers the 357 selected written readings under
H01–H10. E01's finite closure and the static document/source checks are
distinct from this written proof and from unrun grammar execution. Wider
grammar, global scope resolution, calculator applications, RH and physical
identifications remain open. The canonical engine and frozen packets are
unchanged.
