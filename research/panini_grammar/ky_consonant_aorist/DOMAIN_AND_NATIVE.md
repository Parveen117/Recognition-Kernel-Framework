# Grade visibility within the operator

## N1. Carrier and memory

Extend the PG126 grammatical carrier with a typed P/A sic continuation. Retain a source record for the vanished ky-a, the immediate phonetic neighbor of iṭ and the owner of the ending. These are different projections of one ordered grammatical history.

## N2. Distinct queries on one state

For the preceding vowel-grade check the 1.1.57 specialization sees the former ky-a, following the explicit avadhīt precedent. For dental/retroflex evaluation the specialization observes the sound actually before iṭ. In the A deletion branch that is a stop. An invariant that always removes all deleted material or always puts it back would fail one of these queries.

## N3. Compatibility

On a legal nominal/role input each y choice has the P or A ending path of H07–H08; the optional retroflex has a preimage only if the y survives. Each projected output has its displayed witness. Consequently the full-carrier construction followed by ordinary zero-reading agrees on each basis request with the written guarded relation. The transpose pairs requests and words on finite support. No global metric or clock adapter is introduced.
