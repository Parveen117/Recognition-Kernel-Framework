# PG138 — A machine-readable Sanskrit clause frame

Monty · 11 November 2026

The clause about milking now has one event, one understood actor and four overt participants. The cow and the milk both have accusative case. Each has its own identity and semantic role. The promise and the causative examples additionally link two events and identify participants shared between them.

[FRAMES.json](FRAMES.json) contains eleven worked readings. [FRAME.schema.json](FRAME.schema.json) specifies their interchange format in JSON Schema 2020-12. [REFERENCES.json](REFERENCES.json) indexes all sixty-five reviewed participant records across the thirty-two source decisions in 1.4.24–55. Each frame selects only the rows it uses. The index retains the prior source packet and record ID; it introduces zero new inflected positions.
