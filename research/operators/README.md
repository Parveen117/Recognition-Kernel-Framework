# Operators

An operator is a rule you can apply to a specified input. It may change the input, measure it, or say which next move is allowed. For example, three Hebrew readings can print as the same word, כתב. Asking for their plurals reveals a difference that the first reading hid. The choice of what to measure is part of the mathematics. [See the spellings and plurals](grammar.md#hebrew-context)

This catalogue identifies **107 operator families** in a review of five research folders alongside the Recognition Kernel Framework. **80** entries give a rule present in a source, including standard mathematical operations invoked there. **23** give a specified model of a source proposal, with the additional choices stated. **4** document finite examples already developed on this GitHub branch. These are counts of the actions catalogued. Several actions are classical, several already occur elsewhere in the framework, and some share a common construction.

## How names and counts work

- **Cultural names follow a specific action.** Uyirmei combines a written consonant and vowel. Lopa makes a marker disappear from the visible output while its history can remain available. Tāla cycle advance counts positions in a rhythm. Each entry says which part of the source use it models.
- **A parameter choice shares the parent entry.** A heat operator that damps a chosen subspace describes both the Śānti example and its selective bond-release case. The 216 Tamil consonant–vowel positions are possible inputs to one formation rule. Multiple names, letters or parameter values do not multiply the count. [Selective damping](fields.md#heat) · [Uyirmei](grammar.md#uyirmei)
- **Different questions can use the same apparatus.** Reading a diagonal and rebuilding a diagonal operator run in opposite directions. Testing a supplied metre returns yes or no. Generating all sequences of a given weight returns a set. The catalogue counts these different tasks separately. [Readout](observation.md#shadow) · [Synthesis](observation.md#synthesis) · [Metre test](sound.md#metre) · [Pattern generation](sound.md#metre-generation)
