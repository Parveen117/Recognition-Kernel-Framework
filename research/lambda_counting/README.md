# Constant-lambda counting mathematics

12 October 2026. Owner: Monty.

This is the continuing counting/cut workstream. The current task is to
develop its mathematics from the counting constructions, with application
to RH deferred. The shared operator engine remains in
[operator_foundation](../../operator_foundation/README.md); this chapter
contains its counting-specific proofs, examples and observer readings.

The construction begins with one fixed marked unit and positive
repetition. Its later algebraic completion, counting operators and
typed cut retain their explicit carriers. Zero names the cut operation;
the additive-neutral element is a separately derived algebraic object.

SE32 removes the need for a global finite-order assumption when the
target is action on a finite counting input. It derives the required
composition aperture from the previous response. Every infinite-order
action considered here still sends each finite input to a finite output.
Infinite state series and analytic convergence are different questions.
