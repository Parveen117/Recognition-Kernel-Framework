# SE32: observer-reading completion and counting calculus

12 October 2026. Owner: Monty.

This chapter grows the constant-unit counting construction itself.
It has no RH objective or curvature step. Its inputs are SE30's
counting basis and operators, SE31's response decoder, and the
unchanged canonical exact arithmetic. The arguments are derived below
from those inputs. No analytic, spectral or geometric theorem is
imported to supply a missing conclusion.

**Certification is the observer reading for its declared target.**
The response bank is the certificate; the decoder states what it reads.
The infinite statements below have written proofs. A finite bank
certifies its stated finite target, without pretending to have acquired
every response of an unknown infinite operator.

## 1. The counting carrier

Use the coefficient ring R=Q[Lambda] already constructed/admitted in
SE30, with Lambda a constant central unit parameter. Let

\[
 P=\bigoplus_{n\ge0}R p_n,\qquad
 Dp_n=n p_{n-1},\quad Dp_0=0,\quad Xp_n=p_{n+1}.
 \tag{SE32.1}
\]

The index n records repetition/selection degree. The vector p_0 is
the identity formula of the later algebra; it is not a new empty
primitive count. In SE30's polynomial chart these are the ordered-
choice polynomials. The present proofs use their counting actions
directly, without transporting in a classical differential theorem.

Write P_m=span_R(p_0,...,p_m). Every state in P has finite counting
support. Coefficient polynomials also have finite unit support. There
is no norm, infinite state series, dagger, metric or physical clock
in this carrier. Additive-neutral states and coefficients retain
their algebraic types. The named zero operation remains the typed
cut \(\mathsf0_{\rm cut}\), specified in section 4.

## 2. Theorem 1: reading completion removes a global order bound

Every R-linear operator A:P->P has a unique locally finite expansion

\[
 \boxed{A=\sum_{j\ge0}a_j(X)D^j,\qquad a_j\in R[z].}
 \tag{SE32.2}
\]

Locally finite means that on an input in P_m only j<=m contribute;
it is an exact finite action, not a numerical limiting prescription.
The a_j can have unbounded degrees as j increases.

Define the coefficient-to-state reading map

\[
 \mathcal B:R[z]\longrightarrow P,\qquad
 \mathcal B\left(\sum_i c_i z^i\right)=\sum_i c_i p_i.
\]

It is an R-module isomorphism fixed by the counting labels. If
y_k=A p_k is the observer response and a_0,...,a_(k-1) have been
decoded, the next coefficient is

\[
 \boxed{a_k={1\over k!}\,
 \mathcal B^{-1}\left(y_k-
       \sum_{j<k}(k)_j a_j(X)p_{k-j}\right).}
 \tag{SE32.3}
\]

Consequently the finite operator
A^[m]=sum_(j=0)^m a_j(X)D^j agrees with A on all P_m, without any
assumption that A has globally bounded order.

For a sequence of operators define convergence by eventual agreement
on each P_m. A sequence is reading-Cauchy when, for every m, all
sufficiently late terms agree on P_m. The full algebra End_R(P) is
complete in this sense and is the completion of the finite polynomial
operator algebra generated by X,D,Lambda. Distinct operators are
distinguished by some finite probe, so this completion is separated.

**Proof.** The counting actions give
D^j p_k=(k)_j p_(k-j) for j<=k and a null response for j>k.
Also \(a(X)p_0=\mathcal B(a)\). Formula (SE32.3) therefore determines a_k
uniquely, with no knowledge of later responses. Induction makes the
partial operator agree on each successive p_k. Conversely any sequence
of finite polynomials a_j defines an R-linear map on P, because each
input uses only finitely many terms and each term has finite output
support. This proves existence, uniqueness and the action claim.

A reading-Cauchy sequence has a definite eventual value on each p_n.
Extend these values R-linearly to obtain a map P->P. It agrees with
the sequence on each finite prefix eventually, hence is its limit.
The partial operators constructed above are finite words in X,D and
Lambda and converge to A. A differing column distinguishes two maps.
QED.

This is a substantial extension of SE31: finite readings can certify
the action on a finite input sector **without a global order bound**.
They still cannot certify the full unknown infinite operator. For
example D^(m+1) is invisible on P_m and visible on p_(m+1).
An arbitrary mathematical response sequence is not automatically an
algorithmically supplied sequence; the executable examples below
have explicit response-generating rules.

The completion is defined by exact stabilization, not by shrinking
real error. It neither asserts analytic convergence nor replaces the
different mass/weighted completions in operator_foundation.

## 3. Theorem 2: composition requests its aperture from the reading

Suppose the observer has read B p_n for 0<=n<=m. Write these finite
responses as

\[
 Bp_n=\sum_k b_{kn}p_k,
 \qquad S_B(m)=\{k:b_{kn}\ne0\text{ for some }n\le m\}.
\]

Here S_B(m) is a finite set directly obtained from the recorded
responses. The response of AB on the entire input prefix is

\[
 \boxed{(AB)p_n=\sum_{k\in S_B(m)}b_{kn}\,(A p_k),
        \quad 0\le n\le m.}
 \tag{SE32.4}
\]

Thus the next required A-readings are exactly the basis indices in
S_B(m) when A is otherwise unrestricted. If a protocol only supplies
prefix banks, the needed endpoint is max S_B(m); an empty set needs
no A-reading. This endpoint is read from B, not fixed in advance.

The set is minimal among universal schemes that only query individual
basis responses of A: omit an index k with some nonnull b_kn and
two operators, agreeing on all queried columns, can give different
AB responses. This is not minimality among arbitrary linear-combination
queries or among operators with additional known relations.

**Proof.** R-linearity gives (SE32.4), which involves finitely many
recorded terms. For necessity change only the unqueried A p_k by p_0.
The nth output changes by b_kn p_0, nonnull when b_kn is nonnull.
This proves the stated minimality. QED.

Composition is jointly continuous for reading convergence. To fix AB
on P_m, first fix B on P_m and then A on the finite set S_B(m).
Once those readings stabilize the product readings stabilize. Associativity
follows directly from successive finite actions on each state.

There is no same-size quotient-algebra shortcut. The maps invisible
on P_m form a left ideal under composition, but generally not a
right ideal: D^(m+1) is invisible there while

\[
 D^{m+1}X p_m=(m+1)!p_0
 \tag{SE32.5}
\]

is visible. Multiplying equally truncated banks can therefore invent
a missing response. Reading completion uses restriction-compatible
response modules and adaptive composition; it does not falsely regard
each prefix module as an algebra quotient.

For a concrete example, let B p_n=p_(2n+1). On P_3 the observer
reads indices 1,3,5,7. Those four A-responses determine AB, even
though the input prefix ends at 3. This operator B is permitted by
Theorem 1 despite having no fixed finite word formula assumed here.

## 4. Theorem 3: the unit cut extends through the reading completion

For q>=0 retain the unit ring
R_q=R/(Lambda^(q+1)) and the labelled counting carrier
\(\overline P_q=\bigoplus_{n\ge0}R_q\overline p_n\).
Let Q_q:P->overline P_q retain the coefficients through unit degree q.
Every A in End_R(P) has a unique descended operator A_q satisfying

\[
 \boxed{A_q Q_q=Q_q A,\qquad
 A_q\overline p_n=Q_q(Ap_n).}
 \tag{SE32.6}
\]

The map A->A_q is a surjective algebra map, and

\[
 (AB)_q=A_q B_q,\qquad
 \ker(A\mapsto A_q)=\Lambda^{q+1}\operatorname{End}_R(P).
 \tag{SE32.7}
\]

The degree-zero formula/operator cut is
\(\mathsf0_{\rm cut}^{\mathcal E}:A\mapsto A_0\).
It has the declared retained target End_Q(overline P_0). It is not
the same type as SE30's degree-one count-preserving cut n Lambda->n u.
Higher q retain labelled Smriti layers with truncated convolution.

For each fixed input prefix P_m, a complete response bank has a finite
maximum unit degree d_m(A), taking it as 0 for an entirely null bank.
Retaining through this degree recovers that entire bank. There need
not be one finite d working for every input prefix. For example
A p_n=Lambda^n p_n has d_m=m, and any fixed unit depth misses later
columns. This is a formula-operator example, not the erasure of the
marked counts under their different graded cut.

The decoder (SE32.3) commutes with retaining unit layers. Full readings
can disclose their finite unit degrees; a truncated reading alone
cannot establish the absence of higher unseen layers.

**Proof.** Central R-linearity gives
A(Lambda^(q+1)f)=Lambda^(q+1)Af, so the action descends uniquely.
Its columns are the recorded columns with unit coefficients retained;
they are still finite. Every R_q-linear map on overline P_q lifts by
choosing polynomial representatives for its finite columns, proving
surjectivity. A map in the kernel has each column divisible by
Lambda^(q+1); removing that formal factor column by column gives an
R-linear endomorphism of P. This proves the kernel and, by action on
each basis state, the product law. Finite support proves the degree
statement; the explicit example proves the lack of a universal depth.
The decoder uses only finite sums, central coefficients and rational
factorials, all preserved by the quotient map. QED.

Unlike the input-prefix restriction in Theorem 2, this unit cut really
is an algebra quotient. Keeping these two observer operations typed
prevents a false composition rule.

## 5. Theorem 4: functions of a count and their sectors

The number operator is derived from the two counting actions:

\[
 N=XD,\qquad Np_n=n p_n.
\]

For any supplied sequence phi(n) in R, define its count-reading operator

\[
 F_\phi p_n=\phi(n)p_n.
 \tag{SE32.8}
\]

No regularity, growth or analytic continuation of phi is needed for
this action on finite counting states. Its coefficients are recovered
solely from successive count readings by

\[
 c_0=\phi(0),\qquad
 c_k={\phi(k)-\sum_{j<k}(k)_j c_j\over k!},\qquad
 \boxed{F_\phi=\sum_{k\ge0}c_k X^kD^k.}
 \tag{SE32.9}
\]

In particular,

\[
 F_\phi F_\psi=F_{\phi\psi},\quad
 F_{\phi+\psi}=F_\phi+F_\psi,\quad F_1=I.
 \tag{SE32.10}
\]

A supplied indicator profile chi taking values in {0,1} yields a
projection F_chi. A partition of count indices yields disjoint sector
projections whose sum acts as the identity, with finite evaluation on
each state even for an infinite partition. These are algebraic
projections; no orthogonality under a new metric is asserted.

For residue sectors modulo a positive integer d, let P_r select n=r
mod d, with r read modulo d. The exact transport rules are

\[
 P_r X=X P_{r-1},\qquad P_r D=D P_{r+1}.
 \tag{SE32.11}
\]

Thus successive counting steps route responses between the labelled
sectors. A prime-selection profile may equally be built from SE30's
divisibility algorithm, setting the identity index and one to the
unselected value. That selects already-defined prime counts; it does
not discover a new prime-distribution law.

If every phi(n) is a unit in R, the inverse action is
F_phi^(-1)=F_(1/phi). For example phi(n)=n+1 yields the exactly
readable inverse of N+I. This uses the existing rational coefficient
completion, not a new analytic inversion theorem.

**Proof.** Counting gives X^k D^k p_n=(n)_k p_n, with the term
absent for k>n. The triangular recurrence (SE32.9) therefore agrees
with phi(n) for every n, proving the expansion and its uniqueness.
The product and projection formulas follow on each p_n. For residue
transport, raising sends n to n+1 and lowering sends n to n-1; the
lowering action on p_0 is null on both sides. The inverse identity is
the product rule with phi(n)/phi(n)=1. QED.

The entire expansion is derived from count-response interpolation.
The sector labels and selected profiles are declared data; arbitrary
physical sectors or frame-independent prime locations are not inferred.

## 6. Theorem 5: an infinite inverse with finite response computation

Let L be strictly lowering in counting degree:
L(P_m) is contained in P_(m-1), with Lp_0 null. Then

\[
 \boxed{G=(I-L)^{-1}=\sum_{k\ge0}L^k,\qquad
 Gf=\sum_{k=0}^{m}L^k f\quad(f\in P_m).}
 \tag{SE32.12}
\]

Both inverse identities hold exactly in End_R(P). To read G on P_m
only the L-responses on that same prefix are needed; every intermediate
response moves downwards. Unit cuts commute with this inverse:
G_q=(I-L_q)^(-1). This is locally finite algebra, with no estimate
of ||L|| and no analytic convergence requirement.

A nontrivial family generated by the existing counting operators is

\[
 L=D+\Lambda X D^2,
 \qquad Lp_n=n\bigl(1+\Lambda(n-1)\bigr)p_{n-1}.
 \tag{SE32.13}
\]

Repeated counted lowering gives the explicit reading

\[
 Gp_n=\sum_{k=0}^n (n)_k
     \prod_{j=0}^{k-1}\bigl(1+\Lambda(n-j-1)\bigr)p_{n-k}.
 \tag{SE32.14}
\]

For example,

\[
 Gp_2=p_2+2(1+\Lambda)p_1+2(1+\Lambda)p_0,
\]
\[
 Gp_3=p_3+3(1+2\Lambda)p_2+
       6(1+2\Lambda)(1+\Lambda)(p_1+p_0).
\]

This G is genuinely outside the finite polynomial operator algebra.
At the degree-zero cut it sends p_n to
sum_(k=0)^n (n)_k p_(n-k), whose p_0 reading is n! for every n.
Any operator of fixed finite D-order r has a null p_0 reading on
p_n for n>r, since powers of X can only raise the remaining index.
Thus no such finite order represents G, although every Gp_n is a
finite exact reading.

**Proof.** Strict lowering gives L^(m+1)f=0 on P_m. Finite geometric
multiplication on that input yields both (I-L)Gf=f and G(I-L)f=f.
This proves a two-sided inverse, hence uniqueness. Its responses use
only lower-index columns. The cut is an algebra map and preserves
lowering, so it preserves the same finite inverse sums. The counting
actions give (SE32.13); induction gives each product coefficient in
(SE32.14). The p_0 argument proves the infinite-order assertion. QED.

This result is tied to the observed/constructed lowering structure.
Raising alone behaves differently: (I-X)f=p_0 has no finite-support
solution, as the top nonnull coefficient of f produces an uncancelled
next-degree term. An infinite state series would require a different
carrier. It is not silently admitted here.

## 7. What is now available

Starting with fixed-unit counting, the construction now contains every
linear map from finite counting states to finite counting states,
through its compatible response sequence. Finite targets are decoded
without a global differential-order bound. Composition chooses its
needed observation indices from the response itself. Unit cuts extend
lawfully, functions of counts form a directly readable subalgebra,
and a generated lowering family has an exact infinite-order inverse.

These are derived extensions of this declared mathematics, not claims
that their standard algebraic mechanisms were previously unknown.
No numerical positivity target, metric, analytic growth estimate or
new geometry is imposed to obtain these results. All historical
application results remain untouched.
