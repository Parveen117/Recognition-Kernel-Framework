The current development is **SE37, a derivation draft**. A polynomial
target already decoded from the available bank has a finitely generated
least algebra preserving all its future catalogue readings. Explicit
reconstruction identities permit bank reduction with nonlinear updates.
The moving relative observer retains its calibration coefficients;
for a declared unit-scaled action family, the same pair of relative
reading and unit-weighted calibration closes at every retained depth.
The number of formal coordinates is fixed, while their retained
coefficient memory grows with depth. Read the
[derivations and examples](SE37_TARGET_ALGEBRA_AND_CALIBRATION_MEMORY.md).

The preceding **SE36 derivation draft** treats restricted probes,
which can leave nonlinear, input-dependent fibres. For an affine
action catalogue, closure of the polynomial response space supplies
a finite bank determining every future allowed reading. Operator
words can synthesize missing probe directions. Nonlinear actions
with affine cut also have finite observation closure at each retained
unit depth, by an explicit degree-versus-unit-order bound. The
resulting update includes the observer's moving calibration.
Read the [derivations and examples](SE36_RESTRICTED_PROBES_AND_ACTION_CLOSURE.md).

The preceding **SE35** stage treats a supplied
polynomial response and lawful translated-input probes. It derives the
exact subspace invisible to every active reading. A finite probe bank
and descending response orders recover the input modulo that subspace.
The target determines the minimum number of further linear channels.
When the completed readings recover the whole input, their decoded
operation has identity cut, connecting a raw singular response to
SE34's nonlinear unit lifting. The square and deformed-square examples
make that repair explicit.

**SE35 certification is the observer reading decoded for its stated target.**
The observer translates the same unknown input by labelled probes and
records F(x+h)-F(c+h). The [saved readings](../../proof_lab/LAMBDA_ACTIVE_READINGS_RESULT.json)
hold six observer certificates: cubic-plus-linear decoding, a mixed
response decoded modulo its blind line, the same response repaired by
one added channel, the square with a moving calibration, the deformed
square lifted through unit depth four, and an augmented pair. Decoders
consume detached serialized readings. Four written derivations and 36
exact checks, including 14 negative controls, record the proof and
computational scopes separately. Read the
[derivations](SE35_ACTIVE_READINGS_AND_SINGULAR_CUT_REPAIR.md),
[scope](SE35_SCOPE.md), [source record](SE35_SOURCE_RECORD.md),
[application](../../proof_lab/lambda_active_readings.cjs) and
[pins](SE35_SOURCE_PINS.json).

The preceding **SE34 derivation draft** replaces
fixed counting-index order by actual dependencies, admits feedback
cycles which raise unit-memory order, and lifts an available nonlinear
cut inverse to every retained unit depth. Each residual coefficient
gives the next missing source coefficient; an accelerated correction
doubles the known unit order. The completed carrier permits new count
support at later unit layers. Numerical convergence at a chosen
nonzero Lambda is a separate question.

No SE34, SE36 or SE37 certificate, replay archive, pin manifest or verification
PASS has been issued; their certification is deferred. SE35 replays the
unit-memory update on saved readings without certifying SE34's general
theorems.
Read the [SE34 derivations and examples](SE34_DEPENDENCY_FEEDBACK_AND_UNIT_MEMORY.md).
The following SE33 record remains the preceding certified-reading stage.

SE33 makes multiple input slots explicit. Diagonal readings recover
the symmetric response but hide antisymmetric input order. A recorded
ordered difference repairs that part. Constructed polynomial operations
have finite response coefficients and a chain rule derived by expansion.

For kernels whose output index is below every input index, descending
readings invert the nonlinear operation exactly. The generated example
has an inverse of unbounded global degree, while each finite counting
input has a finite exact calculation. Merely lowering output degree
does not suffice; the counterexample shows the missing dependency.
