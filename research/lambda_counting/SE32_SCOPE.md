which nine are negative controls. The application uses the canonical
coefficient and Pāṇinian expression engines, the same counting
presentation as SE31, its memory selector, and SE30's positive Count
divisibility. It does not create a second symbolic arithmetic engine.

eight; count-profile expansions and residue routing through index
twelve; residue moduli two, three and five; prime selection through

general proofs, not the finite ranges, establish the infinite statements.

support. This is not a bounded-operator theorem, a metric completion,
an infinite-state-series calculus, a uniform noisy-data decoder, an
analytic convergence result or a computability theorem for every
abstract response sequence. No new prime-distribution law, physical
sector identification, formal proof-assistant result or external review
