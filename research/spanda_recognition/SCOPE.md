# SP1 scope and next obligations

Author: Monty. 1 November 2026.

| Item | Result and assumptions |
|---|---|
| SP1.1 | Ordered affine lift and zero-specialization compatibility for the supplied typed operators and module maps. |
| SP1.2 | A reset exists iff `[b]=0` in `M/im(I-H)`. Over a rational algebra this is also equivalent to existence of a finite-period memory state. |
| SP1.3 | The obstruction transports under a single affine frame change; changing calibration each cycle requires retaining its endpoint data. |
| SP1.4 | On a finite cut-field carrier, nonzero obstruction admits an invariant linear event count; existing sensor access has an exact row-space criterion. Future access reuses MR-04. |
| SP1.5 | Nilpotent transport yields the exact binomial memory polynomial. Its degree and a reset obstruction are separate properties. |
| SP1.6 | Compatible specialization induces the quotient map, but may erase both nonzero obstruction and a coefficient clock. |
| Full-family witness | Four native quarter-turn source steps return exactly; the declared jet-memory attachment accumulates linear and quadratic coefficients. |

New hypotheses: a supplied, repeatable protocol; memory-independent source
actions; linear memory transport with specified affine increments; rational
scalar algebra; compatible specialization. The scalar clock and observer
criterion additionally use finite dimension over a cut field. The example
admits a three-level central jet algebra and a particular shear/increment.

Closed in this stage: reset feasibility, invariant drift detection, observer
access to a linear cycle count and their specified specialization behavior.
Actual initial-state return is not equivalent to reset feasibility.

The first external application now derives H and b from the quantum
calculator's existing convex rotation-and-preparation source. The
[pinned adapter and derivation](https://github.com/Parveen117/quantum-classical-provisional/blob/7563a59f4c38de15be6841d7ee552ad95cf6755a/native_relational_qc/OBSERVER_CYCLE.md)
provide a finite cut-field realization, exact repeated-block propagation,
physical fixed points and a two-coordinate future-observer test. This
particular physical source has zero obstruction. Its retained protocol
counter is declared classical memory; it is not extracted from a qubit.
Neither a full-family quantum derivation nor acquired hardware validation is
claimed by that adapter.

Still open for the programme:

1. Extend the first declared-source attachment to experimentally calibrated
   devices or acquired readings, and justify any full-family lift. The
   calculator attachment closes only the supplied ideal source-model case.
2. Allow memory to change the selected next action or feed back into the
   source, with guards and a well-defined repeatability contract.
3. Extend the observer criterion to incomplete/noisy measurements and give
   an operational acquisition protocol for coefficient readings.
4. Attach a physical duration and dimensional calibration. The integer cycle
   count constructed here does not select seconds or a universal time law.

The supplied affine lift, algebraic quotient and observability criterion have
standard mathematical ancestors. The new RKF attachment is their combination
with the full-family example and the explicit distinction between source
return, memory reset and observable count. Textual analogy is not theorem
evidence. Existing physics, RH, K0, eta-zero and Yang-Mills boundaries are
unchanged; no new physical identification or conjecture closure is asserted.
